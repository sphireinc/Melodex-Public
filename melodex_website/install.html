Quick start

Melodex is intended to be simple at first launch and powerful once your library grows.

Install the app

Download the build for your platform and move Melodex into your apps folder or preferred install location.

Choose a library root

Select the folder where Melodex should organize artists, albums, lyrics, artwork, videos, and metadata files.

Configure optional tools

For import and conversion workflows, configure tools such as yt-dlp, FFmpeg, and optional AI metadata enrichment.

Import and refine

Add local tracks or authorized sources, review metadata confidence, and let Melodex build the library structure.

Recommended setup

For the best experience, keep downloads and enrichment explicit.

  • Use a dedicated music library folder.
  • Keep a backup before bulk repair operations.
  • Use your own AI key or a trusted metadata service.
  • Only import media you own or are authorized to use.
